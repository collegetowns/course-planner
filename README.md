# Free Course Planner

A simple planner for teachers to build, teach and improve a course week by week, year to year.

- Upload a Word (.docx) syllabus, or start from scratch
- Set class dates with a calendar: meeting days, holidays and breaks (Week 1 / Session A, B…)
- Click any cell to edit the topic, readings and assignments; drag to move classes and assignments
- For each week, keep the activity, links (videos, articles) and notes on how class went
- Copy a term forward to next year, with last year's notes shown under each week
- Download the schedule as a Word table, or copy it to paste into Word

Live site: https://courseplanner.collegetowns.org

## Privacy

Everything runs in the browser. Nothing is uploaded or sent anywhere. Work is saved in the teacher's own browser (localStorage), and teachers can download a backup file to keep a copy or move it to another computer.

## Editing the app

The whole app is the single file `index.html`. It has no build step and loads nothing from outside.
